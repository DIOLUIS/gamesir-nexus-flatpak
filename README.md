# GameSir Connect - Linux Edition (v0.96)

Software open-source para configuração, telemetria e gestão de controles GameSir (focado no **GameSir Cyclone 2**) em sistemas Linux.

## Recursos Principais
- **Telemetria em Tempo Real:** Monitoramento a 60Hz para analógicos (L3/R3) e gatilhos (LT/RT).
- **Calibração Avançada:** Ajuste preciso de zonas mortas.
- **Force Feedback:** Controle individual de vibração para os motores pesado e leve via evdev.
- **Mapeamento e Perfis:** Gestão de perfis e mapeamento visual dos botões traseiros M1 e M2.

## Instalação via Flatpak

    flatpak install --user io.github.dioluis.gamesir_nexus
    flatpak run io.github.dioluis.gamesir_nexus
